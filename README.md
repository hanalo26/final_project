### 프로젝트명: YouTrack - 기업 유튜브 콘텐츠 분석 프로젝트
- 목표: 기업 마케팅 담당자가 경쟁사 채널 대비 자사 콘텐츠의 성과를 데이터 기반으로 진단하고, 다음 영상 전략을 스스로 설계할 수 있도록 지원하는 서비스 구축한다.
- 개요: FnB와 IT 도메인 기업 유튜브 채널(롱폼 1,093개·쇼츠 200개) 데이터를 수집·분석해 콘텐츠 성과 예측 모델과 AI를 활용한 분석 자동화 파이프라인을 구축하고, Streamlit 기반의 유튜브 영상 제작 가이드라인 대시보드를 제작한다.
- 기간: 2026.04.08 ~ 2026.05.14
